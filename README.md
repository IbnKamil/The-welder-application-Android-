# Сварщик ПРО

Нативное Android-приложение для специалистов сварочного производства. MVP построен на Kotlin и Jetpack Compose.

## Разделы

- AI-анализ видимых дефектов сварного шва;
- нормативная база из 28 ГОСТов с поиском и офлайн-чтением PDF;
- личная библиотека с импортом PDF, EPUB, FB2 и TXT, офлайн-чтением и закладками;
- учебные курсы;
- интерактивные тренажёры;
- мессенджер и профессиональное сообщество;
- вакансии, портфолио, оборудование и сотрудничество с предприятиями.

В интерфейсе восемь разделов: исходное описание содержит восемь названий, несмотря на упоминание семи кнопок. Нижняя панель прокручивается горизонтально и остаётся удобной на небольших экранах.

## Запуск

1. Откройте проект в актуальной Android Studio.
2. Установите Android SDK 35.
3. Запустите конфигурацию `app` на устройстве или эмуляторе с Android 8.0+.

Сборка из терминала:

```bash
./gradlew assembleDebug
```

ГОСТы хранятся в `app/src/main/assets/gosts`. Они упаковываются в приложение и открываются встроенным постраничным просмотрщиком без подключения к интернету. Текущий набор получен с [awelding.ru](https://www.awelding.ru/standards-gost).

В разделе «Книги» пользователь может выбрать PDF, EPUB, FB2 или TXT через системный проводник. Книга копируется в закрытое хранилище приложения, поэтому остаётся доступной без интернета. В PDF закладка сохраняет страницу, в текстовых форматах — позицию чтения. Удаление данных приложения также удаляет импортированную библиотеку.

## Статус AI

Экран анализа и запрос доступа к камере готовы как интерфейс MVP. Для производственного распознавания требуется отдельный цикл: сбор и экспертная разметка снимков, обучение модели, валидация на независимой выборке, интеграция через TensorFlow Lite/ONNX Runtime и испытания на реальных устройствах. Результат приложения должен считаться предварительным и не заменяет аттестованный неразрушающий контроль.

## Публикация

Перед загрузкой в Google Play необходимо добавить политику конфиденциальности, подписать Android App Bundle, подтвердить права на распространяемые книги и тексты стандартов и заполнить декларацию Data safety.
