# Демонстрационный кадр для `explain-network`

Положите сюда фото шва под именем `demo_weld.jpg`. Команда без `--image`
возьмёт его автоматически.

Рекомендуемый кадр: вертикальный валик крупным планом, цепочка поверхностных
пор по оси шва, RGB (в том числе кадр со смартфона).

Файл не коммитится: это либо ваше фото, либо стоковое превью с водяным знаком.
Для коммерции и Google Play используйте только собственные снимки.
