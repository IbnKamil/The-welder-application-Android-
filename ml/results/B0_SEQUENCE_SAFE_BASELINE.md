# B0 — sequence-safe SSDLite baseline

Дата запуска: 14 августа 2026 года  
Источник выполнения: Google Colab, GPU runtime  
Checkpoint: последняя эпоха `student_final.pt`  
Test: 867 изображений, группы физических производственных серий не пересекаются с train.

## Конфигурация

- LoHi-WELD high + low;
- MobileNetV3-Large SSDLite;
- 50 эпох;
- вход 640×640;
- изображения растягивались до квадрата без сохранения пропорций;
- без class-balanced sampler;
- без photometric augmentation;
- без scheduler;
- выбран checkpoint последней эпохи, а не лучший по validation.

Этот эксперимент сохранён как намеренно простой контроль B0. Его недостатки
исправляются только в B1; результаты B0 задним числом не пересчитываются.

## Предварительные результаты при score floor 0.25

В первой версии evaluator один порог 0.25 применялся и как рабочая точка, и как
нижняя граница PR-кривой. Поэтому значения AP ниже являются **truncated AP**, а не
стандартным AP по confidence floor 0.001. Precision, recall и FP/image при рабочем
пороге 0.25 остаются корректными. Checkpoint должен быть переоценён исправленным
evaluator без повторного обучения.

## Вывод

B0 непригоден для практического развёртывания. Основные наблюдения:

1. `pore` почти не обнаруживается;
2. резкое падение AP при IoU 0.75 указывает на плохую локализацию;
3. растягивание узких weld crops и выбор последней эпохи являются явными confounders;
4. sequence-safe split существенно сложнее случайного image-level split.
